# مذكر

تطبيق إسلامي (PWA) يعمل من المتصفح ويُثبَّت على الهاتف: مواقيت الصلاة، الأذكار، المصحف، القبلة، المسبحة، التقويم الهجري وحاسبة الزكاة.

## التشغيل محليًا
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه كل الملفات.
2. من المستودع: **Settings ← Pages ← Build and deployment**
   اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
3. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

## ملاحظة عن التنبيه
المتصفحات لا تسمح لتطبيق ويب بإطلاق منبّه والتطبيق مغلق. لذلك:
- التنبيه الصوتي والإشعار يعملان أثناء فتح التطبيق أو بقائه في الخلفية.
- للتنبيه المضمون والتطبيق مغلق: من صفحة المواقيت اضغط «إضافة تذكيرات 30 يومًا إلى التقويم»، وسيرنّ منبّه تقويم هاتفك.
